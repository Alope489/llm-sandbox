# Materials note 8

Material family: CoCrFeMnNi
Processing focus: arc melting
Priority property: youngs modulus

Reference context: Porous alumina ceramics generally show lower thermal conductivity as porosity increases because pores reduce effective conductive pathways through the solid phase.

Generated test guidance: For CoCrFeMnNi, design a simulation matrix that sweeps temperature and at least one processing parameter. Track uncertainty bands and document assumptions for boundary conditions.
